# Personal Portfolio Website

A modern, responsive personal portfolio built with React and modern web technologies. Showcase your projects, skills, and experience with a sleek, professional design.

## 🚀 Live Demo

Visit the live portfolio: [https://dev-portfolio-webpage.netlify.app/](https://dev-portfolio-webpage.netlify.app/)

## 📋 Overview

This is a fully responsive portfolio website designed to highlight your professional experience, projects, and skills. Built with React and React Router, it provides a smooth, single-page application experience with modern UI/UX practices.

## ✨ Key Features

- **Responsive Design** - Optimized for desktop, tablet, and mobile devices
- **Modern UI/UX** - Clean and professional interface
- **Fast Navigation** - Smooth page transitions with React Router
- **Project Showcase** - Dedicated section to display your work
- **Skills Display** - Highlight your technical expertise
- **Contact Section** - Easy way for visitors to get in touch
- **SEO Optimized** - Ready for search engine visibility

## 🛠️ Tech Stack

- **Frontend Framework**: React 18
- **Routing**: React Router
- **Styling**: CSS3 with responsive design
- **Build Tool**: Create React App / Vite
- **Deployment**: Netlify

### Language Composition
- JavaScript: 58.3%

## 🏃 Getting Started

### Prerequisites

- Node.js (v14.0.0 or higher)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/baselserhan/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm start
   ```

   The application will open in your default browser at `http://localhost:3000`

### Build for Production

```bash
npm run build
```

This creates a production-ready build in the `build` directory.

## 🎨 Customization

### Colors & Styling
Edit the CSS files in the `src/styles` directory to customize colors, fonts, and layouts.

### Content
Update component files in `src/components` and `src/pages` to add your projects, skills, and personal information.

### Routes
Modify routes in `App.js` or a dedicated routing file to add or remove pages.

## 🚀 Deployment

The portfolio is currently deployed on **Netlify**. To deploy your own:

1. Build the project: `npm run build`
2. Connect your GitHub repository to Netlify
3. Set build command: `npm run build`
4. Set publish directory: `build`
5. Deploy!

[Learn more about Netlify deployment](https://docs.netlify.com/site-deploys/create-deploys/)
